# Changelog

All notable changes to the "ephemera-vscode" extension will be documented in this file.

## [0.1.0] - 2026-01-13

### Added
- Initial release
- Instance management (create, delete, view details)
- Power operations (start, stop, restart)
- System rebuild with OS selection
- Instance renewal
- Remote command execution
- SSH connection integration
- Plans and OS images display
- Auto-refresh functionality
- Status bar integration
- Secure credential storage
- Tree view for instances and plans
- Copy IP and password to clipboard
- Real-time instance state monitoring

### Features
- Support for all Ephemera EVO instance types
- Multi-language OS support (Debian, Ubuntu, CentOS, AlmaLinux, Alpine)
- Configurable settings
- Progress notifications
- Error handling and user feedback
