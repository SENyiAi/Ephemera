# Ephemera VS Code 扩展 - 安装和使用指南

## 📦 安装步骤

### 1. 安装依赖

首先进入扩展目录并安装依赖：

```bash
cd ephemera-vscode
npm install
```

### 2. 编译 TypeScript

```bash
npm run compile
```

### 3. 调试运行

在 VS Code 中：
1. 打开 `ephemera-vscode` 文件夹
2. 按 `F5` 启动扩展开发主机
3. 新窗口会打开，扩展已激活

### 4. 打包发布（可选）

```bash
# 安装 vsce
npm install -g @vscode/vsce

# 打包扩展
npm run package

# 生成 ephemera-vscode-0.1.0.vsix 文件
```

手动安装 .vsix 文件：
1. 打开 VS Code
2. 点击扩展视图
3. 点击 `...` 菜单
4. 选择"从 VSIX 安装..."
5. 选择生成的 .vsix 文件

## 🚀 首次使用

### 配置 API 凭据

1. 打开命令面板：
   - Windows/Linux: `Ctrl + Shift + P`
   - macOS: `Cmd + Shift + P`

2. 输入并选择：`Ephemera: 设置 API 凭据`

3. 输入您的 **Client ID**（格式：`cli_xxxxxxxxxx`）

4. 输入您的 **Secret**（长字符串）

5. 如果凭据正确，会显示"API 凭据设置成功！"

## 💡 功能使用

### 查看实例列表

1. 点击左侧活动栏的 Ephemera 图标（☁️）
2. 在"实例列表"面板中查看所有实例
3. 实例信息包括：
   - 主机名
   - IP 地址
   - 套餐类型
   - 运行状态

### 创建新实例

**方法一：通过按钮**
1. 点击"实例列表"标题栏的 `➕` 按钮

**方法二：通过命令**
1. 打开命令面板 (`Ctrl+Shift+P`)
2. 输入 `Ephemera: 创建新实例`

**创建流程：**
1. **选择套餐**：从列表中选择配置（Micro、Standard、Pro 等）
2. **选择操作系统**：选择 Linux 发行版（Debian、Ubuntu、CentOS 等）
3. **输入时长**：输入使用时长（小时），默认 24 小时
4. **等待创建**：显示进度，通常需要 10-30 秒
5. **获取信息**：创建成功后显示 IP 和密码

### 管理实例

右键点击任意实例，可以：

#### 🔍 查看实例详情
- 显示完整的配置信息
- 实时的 CPU、内存使用情况
- 网络流量统计
- 到期时间

#### 🔌 电源操作
- **启动实例**：启动已关机的实例
- **停止实例**：正常关机
- **重启实例**：重启系统

#### ⚙️ 管理操作
- **续费实例**：延长使用时间
  - 输入续费小时数
  - 显示新的到期时间
  
- **重装系统**：更换操作系统
  - ⚠️ 会清空所有数据
  - 重新选择操作系统
  - 获得新的 root 密码

- **执行命令**：远程执行 Shell 命令
  - 输入要执行的命令
  - 自动等待执行完成
  - 显示命令输出结果

#### 📋 快捷操作
- **SSH 连接**：
  - 在终端打开：直接在 VS Code 终端连接
  - 复制命令：复制 SSH 命令到剪贴板
  - Remote-SSH：使用 Remote-SSH 扩展（开发中）

- **复制 IP 地址**：一键复制实例 IPv4 地址
- **复制密码**：一键复制 root 密码

#### 🗑️ 删除实例
- ⚠️ 此操作不可恢复
- 会提示确认
- 删除后无法找回数据

### 查看可用套餐

在"可用套餐"面板中：
- 查看所有套餐配置
- CPU、内存、磁盘规格
- 当前库存数量
- 鼠标悬停查看详细信息

## ⚙️ 配置设置

### 打开设置

1. 文件 → 首选项 → 设置（或 `Ctrl+,`）
2. 搜索 "Ephemera"

### 可用设置

```json
{
  // API 基础 URL（一般不需要修改）
  "ephemera.apiBaseUrl": "https://app.alice.ws",
  
  // 自动刷新间隔（秒）
  // 设为 0 禁用自动刷新
  "ephemera.autoRefreshInterval": 60,
  
  // 状态栏显示
  // 在底部状态栏显示实例数量
  "ephemera.showStatusBar": true,
  
  // 默认操作系统
  // 1=Debian 12, 3=Ubuntu 20.04, 4=Ubuntu 22.04
  "ephemera.defaultOS": 1,
  
  // 默认套餐
  // 38=Micro, 39=Standard, 40=Pro, 41=Ultra
  "ephemera.defaultPlan": 38,
  
  // 默认使用时长（小时）
  "ephemera.defaultTime": 24
}
```

## 📊 状态栏

底部状态栏显示：
- **图标**：☁️ Ephemera
- **信息**：`活跃实例/总实例` (例如：2/3)
- **操作**：点击刷新实例列表

可以在设置中禁用：
```json
"ephemera.showStatusBar": false
```

## 🔄 自动刷新

### 启用自动刷新

默认每 60 秒自动刷新实例列表和状态。

### 修改刷新间隔

```json
// 每 30 秒刷新一次
"ephemera.autoRefreshInterval": 30
```

### 禁用自动刷新

```json
// 设为 0 禁用
"ephemera.autoRefreshInterval": 0
```

## 💻 常见使用场景

### 场景 1：快速部署开发环境

```
1. 创建实例
   - 选择 Standard 套餐（4C/8G）
   - 选择 Debian 12
   - 24 小时使用时长

2. 等待创建完成（约 15 秒）

3. 复制 IP 和密码

4. SSH 连接
   - 右键 → SSH 连接 → 在终端打开

5. 执行初始化脚本
   - 右键 → 执行命令
   - 输入：apt update && apt install docker.io -y
```

### 场景 2：批量部署测试

```
1. 创建多个实例（不同操作系统）
2. 在每个实例上执行相同的测试脚本
3. 查看详情对比性能
4. 测试完成后批量删除
```

### 场景 3：临时任务实例

```
1. 创建 Micro 实例（最小配置）
2. 使用 1-2 小时
3. 完成任务后立即删除
4. 节省成本
```

## 🐛 故障排除

### 问题：无法看到实例列表

**解决方案：**
1. 检查是否设置了 API 凭据
2. 点击刷新按钮（🔄）
3. 查看 VS Code 开发者工具控制台错误信息
   - 帮助 → 切换开发人员工具

### 问题：创建实例失败

**可能原因：**
1. 套餐库存不足 → 选择其他套餐
2. 账户余额不足 → 充值后重试
3. 网络连接问题 → 检查网络

### 问题：SSH 连接失败

**检查项：**
1. 实例状态是否为"active"
2. IP 地址是否正确
3. 本地是否安装 SSH 客户端
4. 防火墙是否阻止连接

### 问题：凭据验证失败

**解决方案：**
1. 确认 Client ID 格式：`cli_xxxxxxxxxx`
2. 确认 Secret 没有多余空格
3. 重新从控制台复制凭据
4. 重新设置凭据

### 问题：命令执行超时

**说明：**
- 某些命令需要较长时间执行
- 超时后可以手动 SSH 登录查看结果
- 建议分步执行长时间命令

## 🔐 安全建议

1. **凭据安全**
   - VS Code 使用安全存储保存凭据
   - 不会以明文形式保存

2. **密码管理**
   - 复制密码后及时清除剪贴板
   - 首次登录后建议修改密码
   - 使用 SSH 密钥代替密码

3. **实例安全**
   - 定期更新系统
   - 配置防火墙
   - 仅开放必要端口

## 📝 最佳实践

1. **命名规范**
   - 实例会自动分配主机名
   - 可以通过标签或笔记区分用途

2. **资源优化**
   - 根据实际需求选择合适的套餐
   - 不使用时及时关机或删除
   - 定期清理不需要的实例

3. **数据备份**
   - 重要数据定期备份到本地
   - 重装系统前务必备份
   - 使用外部存储服务

4. **成本控制**
   - 合理设置使用时长
   - 到期前及时续费或删除
   - 监控实例数量

## 🎯 快捷键建议

虽然扩展没有预设快捷键，但您可以自定义：

1. 文件 → 首选项 → 键盘快捷方式
2. 搜索 "ephemera"
3. 为常用命令设置快捷键

推荐设置：
- 刷新实例：`Ctrl+Alt+R`
- 创建实例：`Ctrl+Alt+N`
