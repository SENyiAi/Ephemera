# Ephemera

Ephemera EVO 云实例管理工具集。

## 项目结构

- `API_DOCUMENTATION.md` - Ephemera API 完整文档
- `ephemera-vscode/` - VS Code 扩展

## VS Code 扩展

管理 Ephemera 云实例的 VS Code 扩展。

### 安装

```bash
cd ephemera-vscode
npm install
npm run compile
```

按 F5 启动调试。

### 功能

- 创建/删除实例
- 查看状态和详情
- 电源控制
- 远程命令执行
- SSH 连接
- 自动刷新

详见 `ephemera-vscode/README.md`
